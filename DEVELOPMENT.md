# Lab Specimen Management - Development Guide

## 🚀 Quick Start

### Prerequisites
- .NET 9.0 SDK
- Docker & Docker Compose
- Node.js 18+
- PostgreSQL client (optional, for debugging)

### 1. Start Docker Services

```bash
cd /Volumes/CrewDev/NextOne/BlueStar/lab-specimen-management-be
docker compose up -d
```

**Services:**
- PostgreSQL: `localhost:5432` (User: `postgres`, Password: `myPassword`)
- Redis: `localhost:6379`
- MongoDB: `localhost:27017`

### 2. Run Database Migrations

```bash
cd src/LabSpecimenManagement.DbMigrator
NUGET_PACKAGES=../../.nuget-packages dotnet run
```

### 3. Start Backend API

```bash
cd src/LabSpecimenManagement.HttpApi.Host
NUGET_PACKAGES=../../.nuget-packages dotnet run
```

Backend will be available at: **http://localhost:5002**
Swagger UI: **http://localhost:5002/swagger**

## 🔧 Configuration

### Ports
- **Backend API**: 5002 (HTTP)
- **Frontend**: 3001
- **PostgreSQL**: 5432
- **Redis**: 6379
- **MongoDB**: 27017

### Connection Strings

**appsettings.json** (`src/LabSpecimenManagement.HttpApi.Host/appsettings.json`):
```json
{
  "ConnectionStrings": {
    "Default": "Host=localhost;Port=5432;Database=LabSpecimenManagement;User ID=postgres;Password=myPassword;"
  }
}
```

### CORS Configuration

Frontend URLs are already configured in `appsettings.json`:
```json
{
  "App": {
    "CorsOrigins": "http://localhost:3001,http://localhost:3000"
  }
}
```

## 🛠️ Development Workflow

### Adding New Entity

1. **Create Entity** in `src/LabSpecimenManagement.Domain/`
2. **Add DbSet** to `LabSpecimenManagementDbContext.cs`
3. **Create Migration**:
   ```bash
   cd src/LabSpecimenManagement.EntityFrameworkCore
   dotnet ef migrations add AddNewEntity
   ```
4. **Apply Migration**:
   ```bash
   cd ../LabSpecimenManagement.DbMigrator
   NUGET_PACKAGES=../../.nuget-packages dotnet run
   ```

### Adding New API Endpoint

1. **Create DTO** in `src/LabSpecimenManagement.Application.Contracts/`
2. **Create Application Service** in `src/LabSpecimenManagement.Application/`
3. **API Controller** will be auto-generated by ABP

### Testing API

Use Swagger UI: **http://localhost:5002/swagger**

Or use curl:
```bash
# Get access token
curl -X POST http://localhost:5002/connect/token \
  -d "grant_type=password" \
  -d "username=admin" \
  -d "password=1q2w3E*" \
  -d "client_id=LabSpecimenManagement_Swagger"
```

## 🐛 Troubleshooting

### Port Already in Use

```bash
# Kill process on port 5002
lsof -ti:5002 | xargs kill -9

# Kill process on port 5432 (PostgreSQL)
lsof -ti:5432 | xargs kill -9
```

### Database Connection Failed

```bash
# Restart Docker services
docker compose restart

# Or recreate from scratch
docker compose down -v
docker compose up -d
```

### NuGet Package Permission Denied

The project uses local NuGet cache to avoid permission issues:
```bash
NUGET_PACKAGES=/Volumes/CrewDev/NextOne/BlueStar/lab-specimen-management-be/.nuget-packages dotnet run
```

### Migration Failed

```bash
# Check PostgreSQL logs
docker logs lab_postgres

# Drop database and recreate
docker compose down -v
docker compose up -d
sleep 5
cd src/LabSpecimenManagement.DbMigrator
NUGET_PACKAGES=../../.nuget-packages dotnet run
```

## 🌐 API Endpoints
